# ADR-005: Deterministic implementation engine

**Status:** Accepted · 2026-10-05

## Context
The engine recommends what a company tracks. A wrong or unstable recommendation corrupts their data for years. The brief says AI must never silently modify production tracking.

## Decision
- Plans are generated by a deterministic, versioned rules engine (`rules@1`) from catalogues of models, features, events and properties. Every recommendation carries its reason.
- An LLM may later suggest (classify free text including Arabic, propose custom events, name events), but suggestions enter as draft changes that a person approves. The generator name is recorded on each version.
- Mappings from existing event names are suggested by similarity and applied only when accepted.

## Consequences
- Reproducible, testable plans; easy to explain to customers.
- Coverage is limited to what the catalogue knows; unusual businesses fall back to generic events plus custom activation events until LLM suggestions exist.
